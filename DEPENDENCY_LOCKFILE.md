# Dependency lockfile policy

The backend must ship with a generated `package-lock.json` before a production/UAT release.

Generate it from the backend root with:

```bash
npm install --package-lock-only
```

Then verify it with:

```bash
npm run check:deps
```

The lockfile must be committed and deployment should use `npm ci` once the lockfile is present.

## Current migration note

The PostgreSQL → MySQL migration introduced the `mysql2` dependency. A valid lockfile cannot be safely fabricated; it must be generated by npm against the registry (or from an environment with the required npm metadata/cache available). This environment currently has no registry/DNS access, so this release does **not** include a fabricated lockfile.
